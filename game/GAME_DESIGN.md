# 🕶️ 월급루팡: 몰래컴퍼니 — 게임 기획서

> **한 줄 소개**: 상사가 한눈판 사이에 딴짓해서 '루팡 포인트'를 모으고, 인턴에서 회장까지 승진하는
> **리스크&보상 타이밍 × 방치형 타이쿤** 하이브리드 캐주얼 게임.

---

## 1. 시장 분석 & 타깃

| 항목 | 내용 |
|---|---|
| 타깃 | 20~40대 직장인, 출퇴근 지하철 이용자 |
| 이용 상황 | 편도 30~60분, 서서 한 손으로 플레이, 통신 불안정 구간 존재 |
| 세션 설계 | 1회 세션 1~3분, 언제든 끊어도 손해 없음 (자동 저장 + 오프라인 수익) |
| 경쟁 장르 | 방치형 키우기(고양이 스낵바, 버섯커), 하이퍼캐주얼 타이밍 게임 |
| 차별점 | "월급루팡"이라는 강력한 공감 밈 + **잡히면 잃는다**는 긴장감 있는 능동 조작 |

### 왜 이 조합인가
- 순수 방치형은 초반 이탈이 크고, 순수 타이밍 게임은 지하철에서 피로함.
- **능동(홀드 타이밍) + 수동(자동 수익)** 이중 루프로 "집중할 땐 스릴, 지칠 땐 방치"를 모두 제공.
- 직장인 공감 유머(시말서, 칼퇴, 커피 상납)는 스크린샷 공유 → 오가닉 바이럴로 이어짐.

## 2. 코어 루프

```
[홀드] 딴짓 시작 → 콤보 배율 상승 (x1.0 → x5.0…)
   │
   ├─ 상사 "!" 경고 → [놓기] 포인트 저금 (안전)
   │
   └─ 계속 버티기 → 잡히면 미저금 포인트 전액 몰수 + 경고 1회
                     (경고 3회 = 시말서: 저금액 10% 차감)

루팡 포인트(LP) → 업그레이드 구매 → 더 빠른 수익 → 승진(프레스티지) → 영구 배율
```

- **텐션 곡선**: 오래 버틸수록 배율이 커지므로 "한 틱만 더…"라는 푸시-유어-럭 심리 자극.
- **상사 AI**: 일함(3~8초) → 수상함(0.7~1.4초 경고) → 감시(1.5~2.5초) 사이클. 눈치력 업그레이드로 경고 시간 연장.

## 3. 아이템 / 업그레이드 (참신성 포인트)

| 계열 | 아이템 예시 | 효과 |
|---|---|---|
| ⌨️ 타건력 | 무소음 키보드 → 무접점 커스텀 → 홀로그램 키보드 | 초당 기본 수익 ↑ |
| 🧑‍💻 인맥 | 동기 → 후배 → 아웃소싱 → AI 비서 "GPT-대리" | 자동 수익/초 ↑ (오프라인 포함) |
| 👀 눈치력 | 반사필름 모니터, 백미러 스티커, 스마트워치 진동 알림 | 경고 시간 ↑ |
| 💪 배짱 | 아메리카노 샷 추가, 점심 제육 곱빼기 | 최대 콤보 배율 ↑ |
| ☕ 커피 상납 | 상사에게 커피 바치기 (소모품) | 걸려도 1회 무효 (실드) |

## 4. 성장 / 프레스티지

- **직급**: 인턴 → 수습 → 사원 → 주임 → 대리 → 과장 → 차장 → 부장 → 이사 → 상무 → 전무 → 사장 → 회장 (13단계)
- 승진 시 업그레이드 초기화 + **짬바(경력) 영구 배율 +30%/직급** — 방치형 표준 프레스티지 구조.
- **피버**: 랜덤 "🚨 칼퇴 찬스" 발동 시 10초간 전 수익 x3 (세션 재방문 보상).
- **오프라인 수익**: 자동 수익의 50%를 최대 8시간 적립 → 출근길에 켜면 퇴근길 수익 회수.

## 5. 수익 모델 (플레이스토어 출시 기준)

1. **보상형 광고(RV)**: 오프라인 수익 2배 회수, 칼퇴 찬스 즉시 발동, 시말서 취소 — 세션당 자연 노출 2~3회.
2. **광고 제거 + 루팡 패스**(₩5,900 일회성): 핵심 매출원. 직장인 타깃은 IAP보다 일회성 결제 전환율이 높음.
3. **시즌 코스튬**: 명절/연말정산 시즌 한정 사무실 스킨.

## 6. KPI 목표 & 로드맵

- D1 리텐션 40% / D7 20% / 평균 세션 2.5분, DAU당 세션 4회(출근·점심·퇴근·취침 전).
- **v1.0(현재 구현)**: 코어 루프, 업그레이드 5계열, 승진 13단계, 피버, 오프라인 수익, 자동 저장.
- v1.1: 일일 미션, 리더보드(오늘의 월급루팡 랭킹), 사운드/햅틱 강화.
- v1.2: 부서 이동(맵 테마), 동료 컬렉션, 구글 플레이 게임즈 연동.
- v2.0: 회사 차리기(메타 확장), 친구 회사 방문(소셜).

## 7. 기술 스택

- **HTML5 단일 파일** (바닐라 JS, 의존성 0) — 어떤 기기에서도 즉시 실행, TWA(Trusted Web Activity)로 감싸면 그대로 구글 플레이 출시 가능.
- 세로 고정 · 한 손 조작 · `localStorage` 자동 저장 · WebAudio 경량 사운드 · 오프라인 완전 동작.

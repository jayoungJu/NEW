# 🕶️ 월급루팡: 몰래컴퍼니

> 상사 몰래 딴짓해서 포인트를 모으고, 인턴에서 회장까지 승진하는
> **리스크&보상 타이밍 × 방치형 타이쿤** 캐주얼 게임.
> 20~40대 직장인의 출퇴근 지하철 플레이에 최적화.

## 🎮 실행 방법

의존성 없는 단일 HTML 파일입니다.

```bash
# 브라우저에서 바로 열기
open game/index.html

# 또는 로컬 서버로
cd game && python3 -m http.server 8000
# → http://localhost:8000
```

모바일: 파일을 열거나 호스팅 후 접속. **세로 화면 · 한 손 조작** 전용 설계.
데스크톱 테스트: 마우스 클릭 홀드 또는 **스페이스바** 홀드.

## 🕹️ 플레이 방법

1. 버튼을 **꾹 누르면** 딴짓 시작 — 누를수록 콤보 배율 상승 (최대 x7)
2. 부장님이 **"!"** 경고를 띄우면 얼른 손을 떼서 포인트 저금
3. 계속 버티다 걸리면 미저금 포인트 전액 몰수, 경고 3회면 시말서(LP 10% 차감)
4. LP로 장비 구매: ⌨️ 키보드(홀드 수익) · 🧑‍💻 인맥(자동 수익) · 👀 눈치력(경고 시간) · 💪 배짱(최대 배율) · ☕ 커피 상납(실드)
5. 누적 LP를 채워 **승진** — 장비는 초기화되지만 영구 배율 +30%
6. 앱을 꺼도 자동 수익의 50%가 최대 8시간 적립 (출근길에 켜서 회수!)

## 🚀 플레이스토어 출시 경로

바닐라 JS 단일 파일이므로 [TWA(Trusted Web Activity)](https://developer.chrome.com/docs/android/trusted-web-activity/)
또는 Capacitor로 감싸면 그대로 Android 앱으로 패키징할 수 있습니다.
`localStorage` 저장 · 완전 오프라인 동작이라 지하철 통신 끊김 구간에서도 문제없이 플레이됩니다.
